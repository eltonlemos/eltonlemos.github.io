Human Segmentation Simulation on NVIDIA Isaac Sim

A full Software-in-the-Loop (SIL) simulation using Isaac Sim and ROS2, where a Nova Carter robot equipped with a camera detects humans in real-time using a U-Net-based segmentation model.

Overview

This project demonstrates an end-to-end simulation in NVIDIA Isaac Sim using a ROS2-integrated Nova Carter robot equipped with a camera to perform real-time human segmentation. The environment, robot, sensors, and deep learning model are fully integrated to test perception in a realistic warehouse setup.

Simulation Environment

I used the warehouse.usd file from Isaac Sim as the base environment and added assets like people, forklifts, and obstacles via the Isaac Assets tab.

Robot Setup

While Isaac Sim provides a ready-to-use ROS2 version of Nova Carter, I chose to start from the base robot USD. I created a custom action graph, configured the rosbridge, and wired the sensors manually to better understand the simulation stack. I also added a camera sensor for vision tasks and configured teleoperation via ROS2 using a differential drive controller.

Differential Drive Action Graph

The following nodes were used to build the differential drive logic:

  • ROS2 Context: Initializes ROS2 integration in the simulation.
  • On Playback Tick: Triggers graph updates on every simulation step.
  • ROS2 Subscribe Twist: Subscribes to velocity commands from ROS2 topic /cmd_vel.
  • Scale To/From Stage Units: Converts values between ROS units and simulation units.
  • Break 3-Vector (x2): Splits linear and angular velocities.
  • Make Array: Prepares command array for the controller.
  • Differential Controller: Calculates wheel speeds based on input velocities.
  • Articulation Controller: Sends the joint commands to the robot wheels.
  • Constant Token (x2): Specifies wheel joint paths.

People Segmentation Model

I trained a semantic segmentation model using NVIDIA's PeopleSemSegNet, based on the U-Net architecture.

For data, I used Isaac Sim's Synthetic Data Generation Tool to create 4,000 randomized warehouse environments with human placements and obstacle variations. The tool generated segmentation masks and bounding boxes automatically.

Training was done over 200 epochs with a batch size of 16 on my NVIDIA RTX 3080 (8GB VRAM), taking approximately 5 hours.

The model's performance showed only a small deviation in mIoU compared to NVIDIA's base model, confirming the quality of the synthetic dataset.

Software-in-the-Loop Pipeline

  1. Generate synthetic environments with human/object assets.
  2. Use Isaac Sim to export annotated images (segmentation masks + bounding boxes).
  3. Train U-Net segmentation model on synthetic data.
  4. Deploy trained model back onto the simulated robot.
  5. Use ROS2 to process camera feed and run segmentation in real time.

Conclusion

I successfully built an SIL simulation pipeline integrating ROS2, Isaac Sim, synthetic data generation, and semantic segmentation for real-time perception tasks.

Through this project, I gained deep insight into robot modeling, ROS2 integration, synthetic dataset generation, action graph design, and training segmentation models using synthetic data.
